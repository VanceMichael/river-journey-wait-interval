# 数据字典

合成记录采用 UTF-8 JSON 数组。主键和字段名称见 `manifest.json`。空值为来源未提供。

minute/depart 为当天 00:00 后分钟。水域有效区间左闭右开，日期及分钟均用营业地本地时间。设备归属以日、实际航次及接收时间窗为准，离泊到实际靠泊前才有等待暴露。单一时刻归属证据冲突则保留不确定区间。有离泊且含退款单时，未退款人数计为该已出发航段上的人数下限，闲置席位不自动补齐。联票以首个实际开始的航段进入旅程单位。

- `sailings.json`　售票航次确切的设备借用、码头和实际驶离情况。
- `berth.json`　实际事件及可查日期，enter-queue 为码头记录的进入候泊区。
- `positions.json`　设备按日的定位点以及速度。
- `tickets.json`　联票包含按顺序相连的售票航段，退款席位不必等于全单人数。
- `zones.json`　水域功能和有效区间。
- `traffic.json`　日型与通行限制。
- `advice.json`　以分钟记的历史到达告知。
